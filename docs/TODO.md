# Z8 功能 TODO

更新日期：2026年10月12日。

本清单记录 Z8 的用户功能目标及当前研究进度。独立副本或本地仿真通过，不代表实现已经并入本仓库公开分支，也不代表实体相机验证通过。复选框按对应阶段勾选；局部研究完成时，整体功能仍保持待办。现有菜单与模拟取景基线见[实施记录](z8-status.md)。

## 后续候选功能

这些项目已经讨论，可以作为后续候选；当前没有完成对应的Z8新增功能。

本节15项候选逐项均为：**实现：未实现；验收：未做 Z8 功能验收；公开复现：当前只有本清单中的目标说明，没有对应 Z8 可运行实现**。其他机型的参考代码不计为 Z8 实现；后续有进展时单独更新对应项。

- [ ] **风格包围输出**：一次拍摄生成多种滤镜风格的照片。当前进度：已讨论，未实现。
- [ ] **曝光伪色**：用颜色直观显示曝光区间。当前进度：已讨论，未实现。
- [ ] **矢量示波器**：辅助判断色彩分布和肤色。当前进度：已讨论，未实现。
- [ ] **多比例构图框与遮幅**：同时参考横屏、竖屏、方形等构图。当前进度：已讨论，未实现。
- [ ] **自定义LUT**：导入自己的LUT用于监看，进一步用于照片或视频直出。当前进度：已讨论，未实现。
- [ ] **变形镜头还原监看**：使用变形镜头时显示正确比例。当前进度：已讨论，未实现。
- [ ] **视频预录缓存**：按下录像键后保留此前数秒内容。当前进度：已讨论，未实现。
- [ ] **自动近远端焦点包围**：指定最近和最远焦点，自动规划拍摄序列。当前进度：已讨论，未实现。
- [ ] **机内景深合成**：将不同焦点照片直接合成为一张。当前进度：已讨论，未实现。
- [ ] **长序列实时亮部合成**：持续拍摄并累积星轨、光绘等效果。当前进度：已讨论，未实现。
- [ ] **高像素照片机内合成**：在机内完成像素位移合成，进一步研究手持合成。当前进度：已讨论，未实现。
- [ ] **自定义快门声音**：使用自定义声音文件。当前进度：其他项目有参考，Z8未实现。
- [ ] **MTP传输加速**：提升连接电脑时的文件列表查询等操作速度。当前进度：Z30有参考，Z8未实现。
- [ ] **界面与快捷操作增强**：更灵活的叠加显示、菜单和快捷操作。当前进度：有跨项目参考，尚未形成Z8新增功能。
- [ ] **自动上传至自有云或NAS**：基于现有传输能力接收、整理和同步照片。当前进度：已讨论方案，未实现。
