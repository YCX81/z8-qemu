# Z8 QEMU development checkpoint — 2026-11-11

The `progress/z8-live-20261111` branch preserves source experiments under
`experiments/20261111/`. They are archived separately from the main emulator:

- `wave5/source/`: the prepared QEMU overlay retained in the migrated Live/audio
  workspace. `wave5/*.patch` preserves the Wave5 and merged prepared patches.
- `card-hotplug/`: CFexpress presence/link modeling and diagnostic harnesses.
- `exmcu/`: experimental secondary-MCU port, host-wake patch and native runner.

These patches refer to their original prepared QEMU trees and must not be applied
as a single undifferentiated series to current main. The EXMCU patch includes
broader QEMU configuration changes. Inspect the patch context and prepare the
matching source baseline before an integration attempt. This checkpoint does
not claim that these independent experiments build or pass against main.

The export contains source, not firmware, extracted programs, dumps, camera
media, runtime logs or emulator binaries. Workstation paths use `/path/to/Nikon`
and `/path/to/user` placeholders. Some tools require local firmware, development
trees and laboratory helpers that are deliberately absent. Source licenses and
third-party notices remain applicable; new QEMU experiment contributions follow
GPL-2.0-or-later, consistent with this repository.

The [export manifest](../experiments/20261111/export-manifest.json) records source
and published SHA-256 identities. The publication allowlist enumerates each new
path explicitly. Offline Python parsing passed for all 672 exported Python files
across this repository and the Fenestra snapshot. No QEMU execution, camera USB,
flashing or hardware regression was performed for publication. The existing
publication audit remains a bounded content check, not proof of origin for every
historical instruction-level detail; see [publication boundaries](publication.md).

Firmware-side Live, REC diagnostics, icons, MOV, C64 labels and v36 candidate
sources are archived in [YCX81/fenestra-z8](https://github.com/YCX81/fenestra-z8/tree/progress/z8-live-20261111/research/z8-live).
